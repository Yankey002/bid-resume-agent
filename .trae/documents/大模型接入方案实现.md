# 开发准备计划

## 一、Git仓库配置

### 1. 初始化Git仓库
```bash
git init
```

### 2. 创建.gitignore文件
创建适合Python项目的.gitignore文件，包含常见忽略项：
- 虚拟环境目录
- Python编译文件
- IDE配置文件
- 环境变量文件
- 日志文件等

### 3. 初始提交
```bash
git add .gitignore
git commit -m "Initial commit"
```

### 4. 分支管理
```bash
# 创建main分支（默认分支）
git branch main

# 创建dev分支
git branch dev

# 设置默认分支为main
git checkout main
```

### 5. 分支保护建议
- main分支：设置为保护分支，只允许通过PR合并
- dev分支：开发分支，所有开发工作在此进行
- 建议配置：
  - 禁止直接push到main
  - 合并前需要代码审查
  - 合并前需要通过CI检查

## 二、Python代码检查配置

### 1. 依赖工具选择
- **代码风格检查**：flake8（PEP8规范）
- **代码格式化**：black
- **导入排序**：isort
- **类型检查**：mypy
- **测试框架**：pytest
- **预提交钩子**：pre-commit

### 2. 创建配置文件
- `requirements.txt`：项目依赖
- `.flake8`：flake8配置
- `pyproject.toml`：black和isort配置
- `mypy.ini`：mypy配置
- `.pre-commit-config.yaml`：pre-commit钩子配置

### 3. 配置内容
- **flake8**：设置行长度、忽略规则等
- **black**：设置行长度等
- **isort**：与black兼容的导入排序规则
- **mypy**：基本类型检查配置
- **pre-commit**：配置各检查工具的钩子

### 4. 安装和激活
```bash
# 安装依赖
pip install -r requirements.txt

# 安装pre-commit钩子
pre-commit install
```

## 三、目录结构
```
.
├── .gitignore          # Git忽略文件
├── .flake8             # flake8配置
├── pyproject.toml      # black和isort配置
├── mypy.ini            # mypy配置
├── .pre-commit-config.yaml  # pre-commit配置
└── requirements.txt    # 项目依赖
```

## 四、使用说明
1. 开发时切换到dev分支：`git checkout dev`
2. 提交前会自动运行代码检查
3. 开发完成后，从dev分支创建PR到main分支
4. 合并到main分支后自动部署（根据用户需求）
